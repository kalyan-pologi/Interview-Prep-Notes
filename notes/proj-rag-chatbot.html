🤖 Medical RAG Chatbot: Streamlit, FAISS, HuggingFace

Retrieval-Augmented Generation chatbot for grounded medical Q&A

Built a Retrieval-Augmented Generation chatbot that provides medical information sourced from The Gale Encyclopedia of Medicine. The goal was accurate, source-grounded answers with real-time document retrieval and a clean chat interface, instead of a plain LLM answering from memory alone with no way to verify where an answer came from.

Key Features

  • RAG-based Q&A, combines semantic search with generative answers for precise, contextual responses.
  • Document retrieval with FAISS, vector similarity search for efficient access to relevant chunks from a large medical encyclopedia.
  • LLM-powered responses, uses HuggingFace's google/flan-t5-small model for natural language answers.
  • Streamlit chat UI, conversation history and source expansion built in.
  • Source-aware, every answer includes reference excerpts from the original document to improve trust and traceability.
  • Cloud-friendly, modular setup using Python 3.8+, dotenv for secrets, and a pre-built vector store.

Tech Stack

  • Frontend/UI: Streamlit chat interface
  • LLM: HuggingFace Inference API (flan-t5-small)
  • Embeddings: sentence-transformers/all-MiniLM-L6-v2
  • Vector DB: FAISS
  • RAG chain: LangChain's RetrievalQA with a custom prompt
  • File parsing: PyPDFLoader (via LangChain)
  • Environment management: python-dotenv
  • Corpus: The Gale Encyclopedia of Medicine (Second Edition)

Workflow

  1. PDF ingestion, loads encyclopedia content using PyPDFLoader.
  2. Chunking, splits text using RecursiveCharacterTextSplitter, 500 character chunks with overlap.
  3. Embedding and storage, embeds chunks using HuggingFace embeddings and stores them in FAISS locally.
  4. Question answering, a user question retrieves the relevant chunks from FAISS, passes them to the LLM, and the response is generated and displayed with its source excerpts.
