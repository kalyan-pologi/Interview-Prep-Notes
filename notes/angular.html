Angular core concepts, definitions and use cases.

Components

The basic building blocks of an Angular application. A component controls a portion of the UI, with an associated template (HTML), styles (CSS), and logic (TypeScript). A HeaderComponent for the navigation bar, a ProductListComponent to show items, a UserProfileComponent to show user info.

Services & Dependency Injection

Reusable classes for business logic, data fetching, or utility functions, injected into components through Angular's dependency injection system rather than instantiated directly. An AuthService handling login/logout, a UserService fetching profiles from an API, a DataService managing shared application state.

Directives

Classes that change the DOM's structure or behavior.

  • Structural directives change DOM structure, *ngIf, *ngFor
  • Attribute directives change appearance or behavior, [ngClass], [ngStyle]
<div *ngIf="isLoggedIn">Welcome back</div>
<div [ngClass]="{active: isActive}">Item</div>
<li *ngFor="let item of items">{{ item.name }}</li>

Pipes

Transform data directly in the template without touching component logic.

{{ today | date:'shortDate' }}
{{ price | currency:'USD' }}
{{ name | uppercase }}
{{ items | filter:searchTerm }}

Data Binding

  • Interpolation {{ }}, displays component data in the template
  • Property binding [ ], binds a component property to an element attribute
  • Event binding ( ), handles a DOM event
  • Two-way binding [( )], combines property and event binding into one
<input [(ngModel)]="username">
<button (click)="login()">Login</button>
<img [src]="imageUrl">
<p>{{ userMessage }}</p>

Event Handlers

Component functions that respond to user actions, click, input, submit, and so on. A button click calling addToCart(product), a form submission triggering registerUser(), an input change calling onSearch($event).

HttpClientModule

Provides the tools for communicating with backend APIs over HTTP, fetching data, sending login credentials, uploading files.

Forms

  • FormsModule, template-driven forms, simple and declarative, good for small forms
  • ReactiveFormsModule, reactive forms, programmatic and scalable, better for complex validation and dynamic form structures

Used for login forms with required/email validation, multi-step checkout flows built from reactive form groups, and dynamic forms with conditional fields.

Routing

Navigation between views without a full page reload, the core of a single-page application.

  • Basic routes, /home, /about, /contact
  • Parameterized routes, /products/:id, /users/:userId/profile
  • Nested routing for complex layouts
  • Route guards for authentication and authorization
  • Lazy loading for faster initial page load

Animations

Angular's animation API, built on top of the Web Animations standard, for smooth UI transitions. Fading notifications in and out, sliding in a side nav, loading spinners, page transitions, hover states.

Testing

Unit tests with Jasmine and Karma, end-to-end tests with Protractor or Cypress.

  • Unit testing, individual components, services, and functions in isolation
  • Integration testing, how components interact with each other
  • E2E testing, complete user workflows through the running application
