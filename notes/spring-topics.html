Spring

🍃 Spring Framework Topics

Definitions and use cases for Spring Framework concepts: core IoC/DI, Spring Boot, AOP, MVC/REST, Security, Data JPA, caching, integration/batch/cloud, WebFlux, scheduling/events, and transactions.

Core / IoC / DI

Spring Framework

Comprehensive framework for enterprise Java applications providing IoC, AOP, and integration capabilities. Use case: enterprise applications, dependency management, modular development.

Inversion of Control (IoC)

Design principle where object creation and wiring is handled by the Spring container. Use case: loose coupling, testability, configuration management.

Dependency Injection (DI)

IoC implementation where dependencies are injected into objects rather than created internally. Use case: testable code, modular design, configuration flexibility.

ApplicationContext

Advanced IoC container providing enterprise features like AOP, internationalization, event handling. Use case: enterprise applications, resource management, bean lifecycle.

BeanFactory

Basic IoC container for simple dependency injection. Use case: lightweight applications, memory-constrained environments, basic DI needs.

Bean Lifecycle

Managed object lifecycle: instantiation, dependency injection, initialization, destruction. Use case: resource management, cleanup operations, initialization logic.

Bean Scopes

Defines bean instance creation strategy: singleton, prototype, request, session, application. Use case: state management, performance optimization, web applications.

@Component

Marks a class as a Spring-managed bean for component scanning. Use case: auto-detection, service layer classes, general-purpose beans.

@Service

Specialization of @Component for service layer classes. Use case: business logic layer, service classes, semantic clarity.

@Repository

Specialization of @Component for the data access layer with exception translation. Use case: DAO classes, database operations, exception handling.

@Controller

Specialization of @Component for web layer request handlers. Use case: MVC controllers, request mapping, web applications.

@Configuration

Marks a class as configuration containing @Bean methods. Use case: Java-based configuration, bean definitions, application setup.

@Bean

Method-level annotation creating Spring-managed beans. Use case: third-party object integration, custom bean creation, configuration methods.

@Autowired

Automatic dependency injection by type. Use case: constructor, field, setter injection, reducing boilerplate code.

@Qualifier

Resolves ambiguity when multiple beans of the same type exist. Use case: bean selection, dependency disambiguation, specific bean injection.

@Primary

Gives precedence when multiple beans of the same type exist. Use case: default bean selection, preference indication, autowiring conflicts.

@Value

Injects values from properties files or expressions. Use case: configuration values, property injection, externalized configuration.

@ConfigurationProperties

Maps properties to POJO fields for type-safe configuration. Use case: hierarchical properties, configuration validation, type safety.

@Profile

Conditional bean creation based on active profiles. Use case: environment-specific beans, deployment flexibility, configuration switching.

@Conditional

Creates beans based on custom conditions. Use case: complex conditional logic, feature toggles, environment-based configuration.

@PostConstruct

Method executed after dependency injection completion. Use case: bean initialization, resource setup, post-injection logic.

@PreDestroy

Method executed before bean destruction. Use case: resource cleanup, connection closing, graceful shutdown.

@PropertySource

Specifies property files for configuration. Use case: external configuration, environment-specific properties, configuration management.

@Import

Imports additional configuration classes. Use case: configuration composition, modular configuration, configuration reuse.

BeanPostProcessor

Processes beans before/after initialization. Use case: bean modification, proxy creation, custom initialization logic.

BeanFactoryPostProcessor

Modifies bean definitions before instantiation. Use case: configuration modification, bean definition customization, framework integration.

Spring Boot

Spring Boot

Opinionated framework providing auto-configuration and embedded servers. Use case: rapid development, microservices, standalone applications.

Auto-Configuration

Automatic bean configuration based on classpath dependencies. Use case: reducing boilerplate, convention over configuration, quick setup.

@SpringBootApplication

Combines @Configuration, @EnableAutoConfiguration, @ComponentScan. Use case: main application class, Spring Boot startup, component scanning.

@EnableAutoConfiguration

Enables Spring Boot's auto-configuration mechanism. Use case: automatic bean creation, dependency-based configuration, rapid setup.

Spring Boot Starter

Pre-configured dependency bundles for specific functionality. Use case: simplified dependency management, quick project setup, best practices.

Spring Boot Actuator

Production-ready features for monitoring and management. Use case: health checks, metrics, application monitoring, DevOps integration.

ApplicationRunner vs CommandLineRunner

Interfaces for running code after application startup. Use case: initialization tasks, data loading, startup operations.

Spring AOP

Spring AOP

Aspect-Oriented Programming for cross-cutting concerns. Use case: logging, security, transactions, monitoring, caching.

@Aspect

Marks a class as an aspect containing advice and pointcuts. Use case: cross-cutting concern implementation, modular design, separation of concerns.

@Pointcut

Defines where advice should be applied. Use case: advice targeting, method selection, aspect configuration.

@Before

Advice executed before method execution. Use case: pre-processing, validation, logging, security checks.

@After

Advice executed after method execution (regardless of outcome). Use case: cleanup, logging, resource management, monitoring.

@AfterReturning

Advice executed after successful method return. Use case: result processing, success logging, post-processing.

@AfterThrowing

Advice executed when a method throws an exception. Use case: exception handling, error logging, cleanup after errors.

@Around

Most powerful advice, wrapping method execution. Use case: performance monitoring, caching, transaction management, complete control.

Spring MVC / REST

Spring MVC

Web framework following the Model-View-Controller pattern. Use case: web applications, REST APIs, request handling, view rendering.

DispatcherServlet

Front controller handling all requests in Spring MVC. Use case: request routing, handler mapping, view resolution, centralized control.

@RestController

Combines @Controller and @ResponseBody for REST API development. Use case: REST APIs, JSON responses, microservices.

@RequestMapping

Maps requests to handler methods with URL patterns. Use case: URL routing, HTTP method mapping, request handling.

@GetMapping/@PostMapping/@PutMapping/@DeleteMapping

Specialized request mappings for HTTP methods. Use case: RESTful services, HTTP-method-specific handling, cleaner code.

@PathVariable

Extracts values from URL path segments. Use case: RESTful URLs, dynamic routing, URL parameters.

@RequestParam

Extracts query parameters from a request. Use case: query string handling, optional parameters, form data processing.

@RequestBody

Maps the request body to a method parameter (usually JSON). Use case: REST APIs, JSON processing, POST/PUT operations.

@ResponseBody

Converts a method's return value to the response body. Use case: JSON responses, REST APIs, AJAX endpoints.

@ModelAttribute

Binds request parameters to object attributes. Use case: form handling, data binding, model population.

Model and ModelAndView

Objects for passing data to views. Use case: MVC pattern, view data passing, template rendering.

ViewResolver

Resolves logical view names to actual view implementations. Use case: view technology abstraction, template resolution, rendering configuration.

@ControllerAdvice

Global exception handling across multiple controllers. Use case: centralized exception handling, error responses, logging.

@ExceptionHandler

Handles specific exceptions in controllers. Use case: exception handling, error responses, graceful error management.

@Valid

Triggers validation on request parameters/body. Use case: input validation, data integrity, error prevention.

@Validated

Spring's validation annotation supporting validation groups. Use case: method-level validation, validation groups, complex validation scenarios.

HandlerInterceptor

Intercepts requests before/after handler execution. Use case: authentication, logging, request preprocessing, response modification.

Spring Security

Spring Security

Comprehensive security framework for authentication and authorization. Use case: application security, user management, access control.

@Secured

Method-level security annotation for role-based access. Use case: method security, role checking, access control.

@PreAuthorize/@PostAuthorize

Expression-based method security. Use case: complex authorization logic, dynamic security, fine-grained access control.

@EnableWebSecurity

Enables Spring Security web features. Use case: security configuration, web security setup, authentication.

@EnableMethodSecurity

Enables method-level security annotations. Use case: method security, authorization, access control.

UserDetailsService

Interface for loading user-specific data during authentication. Use case: custom user loading, authentication, user management.

PasswordEncoder

Interface for password hashing and verification. Use case: password security, authentication, credential management.

SecurityContextHolder

Holds security context for the current thread. Use case: authentication information access, user details retrieval, security context.

CORS Configuration

Cross-Origin Resource Sharing configuration for web security. Use case: frontend-backend communication, API access, web security.

@CrossOrigin

Enables CORS for specific endpoints. Use case: frontend-backend communication, API access, cross-domain requests.

CSRF Protection

Cross-Site Request Forgery protection mechanism. Use case: web security, form protection, token-based security.

OAuth2 Integration

OAuth2 authentication and authorization support. Use case: third-party authentication, SSO, secure API access.

JWT Integration

JSON Web Token support for stateless authentication. Use case: microservices authentication, stateless security, token-based auth.

Spring Data JPA

Spring Data JPA

Simplifies JPA-based data access with repositories. Use case: database operations, CRUD operations, query generation.

JpaRepository

Repository interface providing CRUD and batch operations. Use case: database operations, entity management, data persistence.

@Entity

Marks a class as a JPA entity mapped to a database table. Use case: object-relational mapping, database entities, persistence.

@Table

Specifies table details for entity mapping. Use case: custom table naming, schema specification, database mapping.

@Id

Marks a field as the primary key. Use case: entity identification, database mapping, primary key specification.

@GeneratedValue

Specifies the primary key generation strategy. Use case: auto-generated keys, database sequences, key management.

@Column

Maps an entity field to a database column. Use case: custom column mapping, database constraints, field specification.

@JoinColumn

Specifies the foreign key column for relationships. Use case: entity relationships, foreign key mapping, association management.

@OneToMany/@ManyToOne/@ManyToMany/@OneToOne

Entity relationship mappings. Use case: database relationships, entity associations, relational mapping.

@Query

Custom JPQL or native SQL queries in repositories. Use case: complex queries, custom database operations, performance optimization.

@NamedQuery

Named queries defined at the entity level. Use case: reusable queries, query organization, performance optimization.

@Modifying

Indicates a query modifies data (UPDATE/DELETE). Use case: data modification, bulk operations, non-select queries.

Specification

Type-safe query building using the Criteria API. Use case: dynamic queries, search functionality, complex filtering.

Pageable

Pagination and sorting support for repository methods. Use case: large dataset handling, performance optimization, user experience.

@EntityGraph

Controls the entity fetching strategy to avoid N+1 problems. Use case: performance optimization, lazy loading control, query optimization.

@CreatedDate/@LastModifiedDate

Automatic auditing of creation/modification times. Use case: data auditing, change tracking, timestamp management.

@CreatedBy/@LastModifiedBy

Automatic auditing of creation/modification users. Use case: user auditing, change tracking, accountability.

@Version

Optimistic locking support for concurrent updates. Use case: concurrency control, data consistency, conflict resolution.

Transactions

@Transactional

Declarative transaction management. Use case: data consistency, transaction boundaries, rollback management.

PlatformTransactionManager

Abstraction for transaction management. Use case: transaction handling, commit/rollback operations, transaction coordination.

Transaction Propagation

@Transactional propagation defines how Spring should handle transactions when a method is called within another transaction.

When @Transactional Works

@Transactional only takes effect when the method is public, it is called via the Spring proxy (i.e. from a different bean, not a self-invocation), the bean itself is Spring-managed, and the thrown exception type is one that supports rollback.
