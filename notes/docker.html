DevOps

🐳 Docker

Docker concepts and commands.

Basic info

docker version                     # Show Docker client & server version
docker info                        # Show system-wide Docker info
docker --help                      # Show help for Docker commands

Image management

docker images                      # List all downloaded images
docker pull <image>:<tag>          # Pull image from Docker Hub
docker rmi <image_id>              # Remove an image by ID
docker rmi $(docker images -q)     # Remove ALL images (use carefully)
docker build -t <name>:<tag> .     # Build an image from Dockerfile in current directory
docker tag <image> <repo>:<tag>    # Tag an image for pushing
docker push <repo>:<tag>           # Push tagged image to registry

Container management

docker ps                          # List all running containers
docker ps -a                       # List ALL containers (including stopped)
docker run <image>                 # Run a container from an image
docker run -d <image>              # Run in detached mode (background)
docker run -it <image> /bin/bash   # Run interactively with terminal shell
docker start <container_id>        # Start a stopped container
docker stop <container_id>         # Stop a running container
docker restart <container_id>      # Restart container
docker rm <container_id>           # Remove stopped container
docker rm -f <container_id>        # Force remove running container
docker rm $(docker ps -aq)         # Remove ALL containers (use carefully)
docker rename <old> <new>          # Rename container

Logs, inspect, execute

docker logs <container_id>         # Show logs for a container
docker logs -f <container_id>      # Follow live logs (Ctrl+C to stop)
docker exec -it <container_id> bash # Open a shell inside running container
docker inspect <container_id>      # Show detailed JSON info about a container
docker top <container_id>          # Show running processes in container
docker stats                       # Live view of CPU, memory, network usage

Volumes & networks

docker volume ls                   # List all volumes
docker volume create <vol_name>    # Create a named volume
docker volume rm <vol_name>        # Remove a volume
docker network ls                  # List all networks
docker network inspect <net_name>  # Show network details
docker network create <net_name>   # Create a custom bridge network
docker network rm <net_name>       # Remove a network
docker network connect <net> <ctr> # Connect container to a network
docker network disconnect <net> <ctr> # Disconnect container from network

Cleanup

docker system prune                # Remove unused containers, networks, and dangling images
docker system prune -a             # Remove ALL unused images (be cautious)
docker volume prune                # Remove unused volumes
docker network prune               # Remove unused networks
docker builder prune               # Clean build cache

Ports & mounts (run flags)

docker run -p 8080:8080 <image>         # Map host port 8080 to container port 8080
docker run -v D:\data:/app/data <image> # Mount local folder into container
docker run --name <ctr_name> <image>    # Assign a name to container
docker run --env KEY=value <image>      # Pass environment variables

Docker Compose

docker-compose up                  # Start all services (foreground)
docker-compose up -d               # Start in detached (background) mode
docker-compose down                # Stop and remove all services, networks, volumes
docker-compose build               # Build/rebuild images from Dockerfiles
docker-compose restart             # Restart all containers
docker-compose ps                  # Show running services
docker-compose logs -f             # Tail logs from all services
docker-compose exec <svc> bash     # Exec into a service container
docker-compose stop <svc>          # Stop a specific service
docker-compose rm <svc>            # Remove stopped service container
docker-compose config              # Validate docker-compose.yml
docker-compose pull                # Pull latest images for services

Container file system & copy

docker cp <ctr_id>:/path/in/container /host/path  # Copy from container to host
docker cp /host/path <ctr_id>:/path/in/container  # Copy from host to container
docker export <ctr_id> > container.tar            # Export container filesystem
docker import container.tar <image_name>          # Create image from exported tar

Troubleshooting

docker inspect <container_id> | more  # Inspect config/details
docker events                        # Monitor real-time Docker events
docker logs -f <container_id>        # Stream container logs
docker ps --filter "status=exited"   # Find stopped containers
docker-compose up --build --remove-orphans # Clean rebuild

Daily dev workflow

# 1. Build all services
docker-compose build
# 2. Start all services (detached)
docker-compose up -d
# 3. View live logs
docker-compose logs -f
# 4. Stop all services
docker-compose down
# 5. Remove everything (full reset)
docker system prune -a --volumes
