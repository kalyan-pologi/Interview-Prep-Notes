JavaScript reference.

Variables & Data Types

Storing and manipulating different kinds of data, user info, arrays, objects, dynamic data storage.

const userName = "John";
let age = 25;
const products = ["laptop", "phone", "tablet"];
const user = { name: "John", email: "john@example.com" };

Functions

Reusable blocks of code for a specific task, event handlers, data processing, API calls.

function handleClick() {
  console.log("Clicked!");
}

const calculateTotal = (items) =>
  items.reduce((sum, item) => sum + item.price, 0);

async function fetchUserData(id) {
  const response = await fetch(`/api/users/${id}`);
}

DOM Manipulation

Dynamically changing HTML elements and their properties, updating content, adding elements, wiring up event listeners.

document.getElementById("title").textContent = "New Title";
const newDiv = document.createElement("div");
document.body.appendChild(newDiv);
button.addEventListener("click", handleClick);

Event Handling

Responding to user interactions and browser events, form submission, keyboard shortcuts, dynamic interactions.

form.addEventListener("submit", (e) => {
  e.preventDefault();
  processForm();
});

document.addEventListener("keydown", (e) => {
  if (e.ctrlKey && e.key === "s") save();
});

element.addEventListener("mouseenter", showTooltip);

Asynchronous JavaScript

Handling operations that do not block code execution, API requests, timers, file operations, database queries.

fetch("/api/data")
  .then(response => response.json())
  .then(data => updateUI(data));

const userData = await getUserById(123);
setTimeout(() => hideNotification(), 3000);

Array Methods

Built-in methods for transforming arrays without writing manual loops, filtering data, transforming data, finding items, reducing values.

const adults = users.filter(user => user.age >= 18);
const userNames = users.map(user => user.name);
const user = users.find(u => u.id === 123);

Object-Oriented Programming

Organizing code with classes and objects for structure, user classes, component patterns, data models, encapsulation.

class User {
  constructor(name, email) {
    this.name = name;
    this.email = email;
  }
}

class Product {
  calculateDiscount() {
    return this.price * this.discountRate;
  }
}

Local Storage & Session Storage

Storing data in the browser between sessions, saving preferences, remembering form data, shopping cart, user settings. localStorage persists across browser sessions, sessionStorage clears when the tab closes.

localStorage.setItem("theme", "dark");
sessionStorage.setItem("formData", JSON.stringify(formObject));
localStorage.setItem("cart", JSON.stringify(cartItems));

Error Handling

Managing runtime errors gracefully, try-catch blocks, API error handling, form validation.

try {
  riskyOperation();
} catch (error) {
  showErrorMessage(error.message);
}

fetch("/api/data").catch(error => showOfflineMessage());
if (!email.includes("@")) throw new Error("Invalid email");

Modules

Organizing code into separate files, exporting utilities, importing functions, default exports.

export const formatDate = (date) => date.toLocaleDateString();
import { formatDate, validateEmail } from "./utils.js";
export default class ApiClient { /* ... */ }

Closures

A function that remembers variables from its outer scope even after that scope has finished running. Used for encapsulation, private variables, function factories, debouncing and throttling.

function makeCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

const counter = makeCounter();
counter(); // 1
counter(); // 2

Promises

An object representing the eventual completion or failure of an async operation, API requests, chaining async tasks, replacing callback hell.

fetch("/api/user")
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));

Async / Await

Syntactic sugar over promises that makes async code read like synchronous code, cleaner sequential logic and error handling with try/catch.

async function loadUser() {
  try {
    const res = await fetch("/api/user");
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}

Callback Hell

Deeply nested callbacks that make code hard to read and maintain, a code smell from legacy async patterns. The fix is switching to promises or async/await.

getUser(id, user => {
  getOrders(user.id, orders => {
    getProducts(orders, products => {
      console.log(products);
    });
  });
});

Prototype & Prototypal Inheritance

Every function and object in JavaScript has a hidden prototype object used to share methods between instances without duplicating them in memory, and to enable inheritance. When a property is not found directly on an object, JavaScript looks up the prototype chain for it.

function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function () {
  console.log("Hello " + this.name);
};

Scope

Defines where a variable is accessible, controls variable visibility and avoids naming collisions across a codebase.

{
  let x = 10; // block scope
}

function test() {
  var y = 20; // function scope
}

const z = 30; // global scope

Hoisting

JavaScript moves declarations to the top of their scope during compilation, before the code actually runs. var declarations are hoisted and initialized as undefined, let and const are hoisted but stay in a temporal dead zone until their actual line executes, which is why using them before declaration throws an error instead of silently returning undefined.
