👋 Intro

Self-introduction for interviews.

I have around four years of experience in the software industry, primarily working on backend systems using Java and Spring Boot to design and build RESTful microservices and event driven applications.

Since a lot of this touches paid transactions and production data other teams depend on, our main focus is on reliability and data correctness.

I build microservices using Core Java and Spring Boot, optimizing for concurrency and multithreading to keep services responsive under load. I've worked across SQL Server, PostgreSQL, and MySQL, use Kafka for asynchronous event processing and Redis for caching, and secure APIs with Spring Security, OAuth2, and JWT. Our services run on Docker and Kubernetes through CI/CD pipelines, hosted on Azure, with comprehensive logging and monitoring to catch issues early. I write tests with JUnit and Mockito, and apply design patterns like Factory, Strategy, and Decorator to keep things modular.

I've worked in Agile environments throughout my career, collaborating with cross functional teams, and more recently using AI assisted development to move faster day to day. I'm looking for a role where I can continue focusing on backend development, distributed systems, and taking on more ownership across the development lifecycle.
