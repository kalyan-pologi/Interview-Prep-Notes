🔄 Redux

Redux core concepts, quick reference.

Redux flow: User action, dispatch action, reducer, new state, UI update.

Store

The central state container holding the entire application state, a single source of truth instead of state scattered across components.

import { configureStore } from '@reduxjs/toolkit';

const store = configureStore({
  reducer: {
    user: userReducer,
    cart: cartReducer,
    products: productsReducer,
  },
});

Actions

Plain objects describing something that happened in the application.

const addToCart = (product) => ({
  type: 'cart/addItem',
  payload: product,
});

const removeFromCart = (productId) => ({
  type: 'cart/removeItem',
  payload: productId,
});

Reducers

Pure functions that take the current state and an action and return a new state, never mutating the original.

const initialState = { items: [], total: 0 };

function cartReducer(state = initialState, action) {
  switch (action.type) {
    case 'cart/addItem':
      return {
        ...state,
        items: [...state.items, action.payload],
        total: state.total + action.payload.price,
      };
    case 'cart/removeItem':
      return {
        ...state,
        items: state.items.filter(item => item.id !== action.payload),
      };
    default:
      return state;
  }
}

Redux Toolkit (RTK)

The official recommended way to write Redux with far less boilerplate than hand-writing action types, action creators, and reducers separately.

  • configureStore(), sets up the store
  • createSlice(), creates a reducer plus its matching action creators together
  • createAsyncThunk(), handles async logic
import { createSlice } from '@reduxjs/toolkit';

const cartSlice = createSlice({
  name: 'cart',
  initialState: { items: [], total: 0 },
  reducers: {
    addItem: (state, action) => {
      state.items.push(action.payload);
      state.total += action.payload.price;
    },
    removeItem: (state, action) => {
      state.items = state.items.filter(item => item.id !== action.payload);
    },
    clearCart: (state) => {
      state.items = [];
      state.total = 0;
    },
  },
});

export const { addItem, removeItem, clearCart } = cartSlice.actions;
export default cartSlice.reducer;

useSelector & useDispatch

useSelector reads data out of the store, useDispatch sends actions into it.

import { useSelector, useDispatch } from 'react-redux';
import { addItem } from './cartSlice';

function CartSummary() {
  const items = useSelector(state => state.cart.items);
  const total = useSelector(state => state.cart.total);
  return (
    <div>
      <p>Items: {items.length}</p>
      <p>Total: ${total}</p>
    </div>
  );
}

function ProductCard({ product }) {
  const dispatch = useDispatch();
  return <button onClick={() => dispatch(addItem(product))}>Add to Cart</button>;
}

Async Actions (Thunks)

Functions that handle async operations, an API call for example, and dispatch actions as the request moves through pending, fulfilled, and rejected states.

import { createAsyncThunk, createSlice } from '@reduxjs/toolkit';

export const fetchUsers = createAsyncThunk('users/fetch', async () => {
  const response = await fetch('/api/users');
  return response.json();
});

const usersSlice = createSlice({
  name: 'users',
  initialState: { list: [], loading: false, error: null },
  reducers: {},
  extraReducers: (builder) => {
    builder
      .addCase(fetchUsers.pending, (state) => { state.loading = true; })
      .addCase(fetchUsers.fulfilled, (state, action) => {
        state.loading = false;
        state.list = action.payload;
      })
      .addCase(fetchUsers.rejected, (state, action) => {
        state.loading = false;
        state.error = action.error.message;
      });
  },
});

Middleware

Functions that intercept an action before it reaches the reducer, used for logging, handling async calls, or catching and reporting errors.

const loggerMiddleware = (store) => (next) => (action) => {
  console.log('Dispatching:', action);
  const result = next(action);
  console.log('Next state:', store.getState());
  return result;
};

const store = configureStore({
  reducer: rootReducer,
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware().concat(loggerMiddleware),
});

Selectors

Functions that extract or derive data from state, often memoized so an expensive calculation only reruns when its inputs actually change.

import { createSelector } from '@reduxjs/toolkit';

const selectCartItems = (state) => state.cart.items;

const selectCartTotal = createSelector(
  [selectCartItems],
  (items) => items.reduce((sum, item) => sum + item.price, 0)
);

function Cart() {
  const total = useSelector(selectCartTotal);
  return <div>Total: ${total}</div>;
}

Provider

The React component that makes the Redux store available to the rest of the app, wrapping the root component.

import { Provider } from 'react-redux';
import { store } from './store';

function App() {
  return (
    <Provider store={store}>
      <YourApp />
    </Provider>
  );
}

Immutability

State is never mutated directly, a new object is always returned instead. Redux Toolkit uses Immer internally, so reducer code can look like it is mutating state directly while it actually produces a new immutable object behind the scenes. Traditional Redux without RTK requires manual spreading.

// Redux Toolkit (Immer under the hood)
reducers: {
  updateUser: (state, action) => {
    state.user.name = action.payload; // looks like mutation, isn't
  },
}

// Traditional Redux
function reducer(state, action) {
  return {
    ...state,
    user: { ...state.user, name: action.payload },
  };
}

DevTools

A browser extension for inspecting Redux state and actions, time-travel debugging, and replaying actions. Enabled by default with Redux Toolkit.

const store = configureStore({
  reducer: rootReducer,
  devTools: process.env.NODE_ENV !== 'production',
});

Complete Setup Example

// store.js
import { configureStore } from '@reduxjs/toolkit';
import userReducer from './features/userSlice';
import cartReducer from './features/cartSlice';

export const store = configureStore({
  reducer: { user: userReducer, cart: cartReducer },
});

// features/cartSlice.js
import { createSlice } from '@reduxjs/toolkit';

const cartSlice = createSlice({
  name: 'cart',
  initialState: { items: [], total: 0 },
  reducers: {
    addItem: (state, action) => {
      state.items.push(action.payload);
      state.total += action.payload.price;
    },
    removeItem: (state, action) => {
      const index = state.items.findIndex(item => item.id === action.payload);
      if (index !== -1) {
        state.total -= state.items[index].price;
        state.items.splice(index, 1);
      }
    },
  },
});
export const { addItem, removeItem } = cartSlice.actions;
export default cartSlice.reducer;

// index.js
import { Provider } from 'react-redux';
import { store } from './store';

ReactDOM.render(
  <Provider store={store}><App /></Provider>,
  document.getElementById('root')
);

// Cart.js
import { useSelector, useDispatch } from 'react-redux';
import { addItem, removeItem } from './features/cartSlice';

function Cart() {
  const items = useSelector(state => state.cart.items);
  const total = useSelector(state => state.cart.total);
  const dispatch = useDispatch();

  return (
    <div>
      <h2>Shopping Cart</h2>
      {items.map(item => (
        <div key={item.id}>
          <span>{item.name}, ${item.price}</span>
          <button onClick={() => dispatch(removeItem(item.id))}>Remove</button>
        </div>
      ))}
      <h3>Total: ${total}</h3>
    </div>
  );
}
