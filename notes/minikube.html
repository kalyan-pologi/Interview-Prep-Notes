📦 Minikube

Minikube concepts and commands.

Cluster lifecycle

minikube start --driver=docker        # Start local K8s cluster using Docker
minikube stop                         # Stop the cluster (keeps data)
minikube delete                       # Delete the cluster completely (full reset)
minikube status                       # Check cluster status
minikube dashboard                    # Open Kubernetes Dashboard in browser

Addons

minikube addons list                  # List all available addons
minikube addons enable ingress        # Enable NGINX Ingress controller
minikube addons disable ingress       # Disable ingress
minikube addons enable metrics-server # Enable resource metrics (for kubectl top)
minikube addons enable dashboard      # Enable Kubernetes dashboard
minikube addons disable dashboard     # Disable dashboard

Network & access

minikube ip                                  # Show cluster's internal IP address
minikube service <service> -n <ns> --url    # Get external URL for a service
minikube tunnel                              # Expose LoadBalancer/Ingress on localhost
minikube ssh                                 # SSH into Minikube VM (Linux shell)
minikube delete --all --purge                # Remove all profiles and cleanup

Docker inside Minikube

minikube docker-env                        # Show env vars to use Minikube's Docker daemon
eval $(minikube -p minikube docker-env)    # (Linux/Mac) Use Minikube's Docker for builds
minikube image build -t <name>:<tag> .    # Build image directly inside Minikube
minikube image ls                          # List images inside Minikube
minikube image rm <image>                  # Remove image from Minikube

Troubleshooting & info

minikube logs                         # View cluster logs
minikube service list                 # List all exposed services
minikube profile list                 # Show all Minikube profiles (clusters)
minikube update-check                 # Check for updates
minikube kubectl -- get pods          # Run kubectl command through Minikube

Typical local setup

minikube start --driver=docker
minikube addons enable ingress
kubectl apply -f k8s/
minikube tunnel          # keep running
kubectl get pods -n microservices
