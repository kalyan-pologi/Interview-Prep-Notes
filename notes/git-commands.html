🔧 Git Commands

Reference for common Git commands.

Setup & Config

  • git init, initialize a new Git repository
  • git config, configure Git settings (username, email, etc.)
  • git clone, copy a remote repository locally
  • git remote, manage remote connections

Day to Day

  • git status, show current changes and staged files
  • git add, stage files for commit
  • git commit, save staged changes to the local repo
  • git push, upload commits to the remote repo
  • git pull, fetch and merge changes from remote
  • git fetch, download changes without merging

Branching

  • git branch, create or view branches
  • git checkout, switch between branches
  • git merge, merge another branch into the current one
  • git rebase, reapply commits on top of another base branch

History & Undo

  • git log, view commit history
  • git diff, show differences between commits or files
  • git stash, temporarily save uncommitted changes
  • git reset, unstage or undo commits
  • git revert, undo a commit by creating a new commit
  • git cherry-pick, apply a specific commit from another branch

Notes from real usage

git rebase keeps history linear, which is nicer to read, but rewrites commit hashes, so it should never be used on a shared branch someone else has already pulled. git merge is safer for shared branches since it preserves history as-is with a merge commit. git revert is the safe undo for anything already pushed since it adds a new commit instead of rewriting history, while git reset is fine for local, unpushed commits only.
