⚡ Quick Revision Guide

Frontend quick revision guide.

Condensed cross-topic cheat sheet, a fast pass over everything in the Frontend section before an interview. See the individual pages for full explanations and examples.

CSS

  • Box model order: content, padding, border, margin
  • Flexbox is one-dimensional (row or column), Grid is two-dimensional
  • Positioning: static (default) < relative (offset, space preserved) < absolute (out of flow, relative to nearest positioned ancestor) < fixed (relative to viewport) < sticky (relative until a scroll threshold, then fixed)
  • Units: px fixed, % relative to parent, em relative to parent font size, rem relative to root font size

JavaScript

  • let/const are block scoped, var is function scoped
  • Hoisting: var hoists as undefined, let/const hoist into a temporal dead zone
  • Closures let an inner function remember its outer scope's variables after that scope returns
  • Prototype chain: a missing property lookup walks up the prototype chain before failing
  • Promises and async/await replace nested callback hell
  • localStorage persists across sessions, sessionStorage clears when the tab closes

TypeScript

  • interface for object shapes (supports merging), type for unions and complex compositions
  • unknown is a type-safe alternative to any, forces a check before use
  • Utility types: Partial, Required, Readonly, Pick, Omit, Record, ReturnType
  • Generics let a function, interface, or class work over a type parameter instead of one fixed type

React

  • Function components with Hooks are the modern default, class components are legacy
  • State updates must create a new reference, mutating in place skips the re-render
  • Keys let React match list items across renders, missing or unstable keys hurt update efficiency and can cause subtle bugs
  • Hooks rules: only call at the top level, only from React functions, always in the same order
  • useMemo memoizes a value, useCallback memoizes a function reference, both exist to avoid unnecessary re-renders

Redux

  • Flow: action dispatched, reducer computes new state, UI re-renders from the new state
  • Reducers must be pure functions, never mutate state directly (Redux Toolkit's Immer makes this look like mutation while staying immutable underneath)
  • useSelector reads state, useDispatch sends actions
  • createAsyncThunk handles async logic with pending/fulfilled/rejected states

Angular

  • Structural directives change DOM structure (*ngIf, *ngFor), attribute directives change appearance/behavior ([ngClass], [ngStyle])
  • Data binding: interpolation {{ }}, property [ ], event ( ), two-way [( )]
  • Services are injected via dependency injection rather than instantiated directly
  • ReactiveFormsModule for complex/dynamic forms, FormsModule for simple template-driven forms
