📄 HTML

HyperText Markup Language reference.

Elements & Tags

Building blocks that structure content using opening and closing tags.

<h1>Main Title</h1>
<p>Text content</p>
<a href="https://example.com">Visit Site</a>

Attributes

Additional information attached to an element.

  • id="header", unique identification for a single element
  • class="container", groups of elements sharing styling
  • data-user="123", custom data attributes for JavaScript access

Semantic HTML

Using elements that describe the purpose of the content instead of generic containers, which helps accessibility tools and search engines understand page structure.

  • <header>, <nav>, <main>, <footer>, overall page structure
  • <article>, <section>, content organization
  • <button> instead of a styled <div> for anything clickable, since a button gets keyboard focus and screen reader support for free

Forms

Interactive elements for user input and data submission.

<input type="email">
<input type="password">
<input type="search" placeholder="Search...">
<input type="file" accept=".pdf,.jpg">
