🎨 CSS

Cascading Style Sheets reference.

Selectors

Patterns used to target HTML elements for styling.

h1 { color: blue; }              /* element */
.button { padding: 10px; }       /* class */
#header { background: white; }   /* id */
[type="email"] { border: 1px solid gray; }  /* attribute */

Box Model

How an element is structured: content, padding, border, then margin, from the inside out.

.card {
  padding: 20px;
  margin: 10px;
  border: 1px solid #ddd;
}

.centered { margin: 0 auto; }
.button { padding: 12px 24px; border-radius: 4px; }

Flexbox

One-dimensional layout for arranging items in a row or a column.

.center { display: flex; justify-content: center; align-items: center; }
.navbar { display: flex; justify-content: space-between; }
.card-grid { display: flex; flex-wrap: wrap; gap: 20px; }

Grid

Two-dimensional layout for more complex arrangements than flexbox handles well.

.page {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}

.dashboard { grid-template-columns: 250px 1fr; }

Responsive Design

Adapting layout to different screen sizes with media queries.

/* Mobile-first */
@media (min-width: 768px) {
  .container { max-width: 1200px; }
}

@media (max-width: 600px) {
  .desktop-only { display: none; }
}

/* Flexible typography without a media query at all */
h1 { font-size: clamp(1rem, 2.5vw, 2rem); }

Animations & Transitions

.card {
  transition: all 0.3s ease;
}
.card:hover { transform: scale(1.05); }

@keyframes spin { to { transform: rotate(360deg); } }
.spinner { animation: spin 1s linear infinite; }

Positioning

  • Static, normal document flow, top/left have no effect. Default for every element.
  • Relative, stays in normal flow but is visually offset, the space it originally occupied is preserved.
  • Absolute, taken out of flow, positioned relative to the nearest positioned ancestor (the closest parent that is not static).
  • Fixed, taken out of flow, positioned relative to the viewport, stays put on scroll.
  • Sticky, behaves as relative until scroll crosses a threshold, then behaves as fixed.

Units

  • px, a fixed size, does not scale with anything
  • %, relative to the parent element's size
  • em, relative to the parent element's font size
  • rem, relative to the root (html) element's font size, generally safer than em since it does not compound across nested elements
